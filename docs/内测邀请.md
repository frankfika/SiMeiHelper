## ② 用户测试指引（10 步，约 15 分钟，含每步「怎么验」「测什么」「怎么报错」）

> Hi 内测伙伴！下面是 5 大场景 10 个必测动作。每条都按"操作 → 预期 → 报错"格式写，照着做就行。
>
> **统一报错**：截图 + 一句话「步骤 X.X 出错，期望 X，实际 Y」发到群 / 我微信。

### 场景 A：装好 + 第一次进入

| # | 你的操作 | 预期 | 你应该看到 |
|---|---|---|---|
| **A1** | 解压 zip → 微信开发者工具「导入项目」→ 选 `SiMeiHelper` 文件夹 → 输任意 AppID → 导入 | 模拟器显示启动页 | 启动页 → 进入第 1 步「欢迎」 |
| **A2** | 关闭调试、清缓存，再次打开 | 直接进入今天页 | 今天页（不需要重新 onboarding） |
| **A3** | 设置 → 清空所有数据 → 输入「清空」二字 | 重启回到第 1 步 | 重新进 onboarding |

**关键红线**：onboarding 6 步必须能走完；如果卡在某一步发我。

### 场景 B：打针记录（最核心）

| # | 你的操作 | 预期 | 报错案例 |
|---|---|---|---|
| **B1** | 今天 tab → 切到「记录」tab → 选「司美格鲁肽」→ 剂量 chip 默认第一档（0.25mg） | 时间默认为「现在」，可改 | 选完跳到下一步 |
| **B2** | 部位 8 格：**必测**：上次打过的位置应显示「上次 M/D」/ 「本周已用」；没用的显示「没用过」 | 推荐格带 primary 描边 + 「推荐」角标 | "上次"显示错 / 推荐格错 |
| **B3** | 时间 picker 改到「距现在 24 小时前」→ 保存 | 弹 modal「距离上一针才 X 小时」 | 没弹 / 弹错文案 |
| **B4** | 剂量从 3 改成 5（**非方案剂量**）→ 保存 | 弹 modal「医生给你调整剂量了吗？」 | 没弹 |
| **B5** | 首次保存后 → 弹「加到日历 / 先不用」 | 没保存则不弹 | 弹了但点不下去 |

**关键红线**：**B3 + B4 必须拦截**。这是安全功能。

### 场景 C：聊天 + 急症守护（最核心）

| # | 你的操作 | 预期 | 报错案例 |
|---|---|---|---|
| **C1** | 设置 → 接入大模型 → 填你自己的 OpenAI 兼容 key → 点「测试连接」 | 显示「连接成功 · XXX ms」 | 「连接失败」/ 一直转圈 |
| **C2** | 切到「小美」tab → 输入「你好」 | 命中 greeting + 4 个推荐问题 chip | 没有 chip |
| **C3** | 输入「最近有点恶心」 | 命中 nausea 意图 + 出现「记到今天打卡」按钮 | 没出现按钮 |
| **C4** | **【急症必测】**输入「肚子疼得厉害，还疼到后背」 | 顶部弹急症卡 + 「拨打 120」按钮 + 「就诊摘要」按钮 | 没弹 / 文案错 |
| **C5** | **【急症必测】**输入「喝水都吐」 | 同 C4（**必须**是「拨打 120」直接拨） | 文案 / 动作错 |
| **C6** | **【急症必测】**输入「我有点轻生的念头」 | 弹出 12356 + 心理援助 | 没弹 |
| **C7** | 输入「我可以把加到 1mg 试试吗」 | 不进 LLM → 规则模板 + 「生成就诊摘要」按钮 | 进了 LLM（说明守卫漏） |

**关键红线**：**C4 / C5 / C6 必须拦截并拨打 / 推援助**。

### 场景 D：打卡 + 趋势

| # | 你的操作 | 预期 |
|---|---|---|
| **D1** | 记录 tab → 输入「177 斤，走了半小时，没胃口」→ 帮我填 | 三个预览：体重 88.5 / 有氧 30 / 没胃口；可点 × 移除 |

| **D5** | 切到「趋势」tab | 图表 + markers + 解读卡 |
